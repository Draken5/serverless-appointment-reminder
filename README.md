# serverless-appointment-reminder
“Serverless Appointment Reminder System using AWS Lambda, API Gateway, and DynamoDB”
## Overview
This project demonstrates a serverless appointment reminder system built on AWS.

## AWS Services Used
- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB

## Steps
1. Created Lambda functions to send reminders
2. Configured API Gateway to trigger Lambda functions
3. Stored and retrieved appointment data in DynamoDB
4. Troubleshot AWS service limits and adjusted configuration

## Architecture
User → API Gateway → Lambda → DynamoDB
